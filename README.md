# robotont.github.io
[Documentation](https://robotont.github.io) for robotont

## Generating the documentation

### Setting up the environment
Set up a virtual python environment and activate it:
```bash
python3 -m venv venv
source venv/bin/activate
```

### Install dependencies to the virtual environment
```
pip3 install --upgrade pip
pip3 install -r requirements.txt
```

### Generating the documentation
* Make whatever changes you need to the docs files in `source/` and then run
```bash
make html
```
* The documentation will be built to `html/`
* You can open the documentation in a browser by opening [html/index.html](html/index.html)

### Cleaning the generated documentation
To clean the html and doctrees generated by Sphinx, run
```bash
make clean
```
