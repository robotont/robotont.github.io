.. _initialize_ROS:
===================================
Setup ROS for Robotont
===================================

This section guides you through setting up ROS to work with Robotont, either in simulation or on the physical robot.

* The **Prerequisites** section is required for both simulation and real-robot usage and ensures that your system is properly prepared.
* The **Visualize** section explains how to clone the core Robotont packages and launch RViz to verify that the robot model loads correctly. These packages are also a fundamental requirement for running Robotont in simulation.
* The final **Connecting to the Robot** section is only necessary when working with the physical Robotont robot and can be skipped if you are using simulation only.
